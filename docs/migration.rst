Migration from 0.6
==================

Version 0.7 is a breaking change. Read the repository's
`migration guide on GitHub <https://github.com/FBarrca/cimba_python/blob/master/MIGRATION.md>`_ for a mapping of old declarations,
entities, traces, bootstraps, experiments, and result access. The old
``cimba.sim`` and ``cimba.bootstrap`` imports raise migration errors.
